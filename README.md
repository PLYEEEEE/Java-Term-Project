# Slime Monster System

A Java project demonstrating an RPG slime monster system with stat scaling and combat mechanics.

## Features

- Slime with scalable stats (HP, damage, speed)
- Wave-based difficulty scaling
- Level progression
- Combat system (attack, damage, death)

## Running the Application

### Console Demo
```bash
cd src
javac -d ../bin *.java
java -cp ../bin SlimeDemo
```

### GUI Tester
```bash
cd src
javac -d ../bin *.java
java -cp ../bin SlimeGUI
```

The GUI provides interactive controls and visual representation to test slime functionality including:

- Visual slime character with movement, attack effects, and death animation
- Real-time HP bar display  
- Interactive controls for attacking, taking damage, wave progression, and movement
